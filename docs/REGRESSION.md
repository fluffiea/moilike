# 重构验收：基线与回归清单

## 1. 测试云环境（真机验证前必做）

1. 云开发控制台 → 环境 → 新建一个测试环境（按量计费，图片缩略图处理需要按量计费环境）。
2. 在测试环境建集合：`users`、`daily_posts`、`daily_comments`、`report_posts`、`bind_requests`、`letters`，权限全部选「仅云函数可读写」。
3. 按 [DATABASE.md](./DATABASE.md) 建索引。
4. `project.private.config.json` 里不要写死 env；开发者工具顶部「云开发」切到测试环境后，上传部署 `cloudfunctions/api`（云端安装依赖）。
5. 用两个微信号（体验成员）登录，互相结伴后跑下面的回归清单。

## 2. 性能基线（重构前，按代码统计）

「云调用」指 `wx.cloud.callFunction` 次数；「串行段」指用户看到完整内容前必须依次等待的往返段数。

| 场景 | 重构前云调用 | 重构前串行段 | 重构后目标 |
|------|------|------|------|
| 冷启动（已登录）到朝夕页完整显示 | 5（`user.getProfile` x2、头像换链 x2、`letters.summary`） | 4，且登录页先阻塞 1 次才跳 Tab | 缓存直出，后台 1 次 `home.summary` |
| 浮生首屏 | 3（`daily.listDaily` + 配图换链 + 头像换链，跨 2 个函数） | 2 | 1 |
| 共鸣首个 Tab | 3（同上） | 2 | 1 |
| 日常详情 | 4（详情 + 评论并行，再配图 + 头像换链） | 2 | 1 |
| 从详情返回浮生 | 3（`getDailyFeedItem` + 2 次换链） | 2 | 0（本地 store 同步） |
| 报备详情 | 3 | 2 | 1 |
| 独白页每次显示 | 1~3（60 秒节流 + 2 次头像换链） | 2 | 0~1（读 store，后台刷新） |
| 结伴页 | 3（面板 + 对方头像 + 申请人头像） | 2 | 1 |

服务端每个列表/详情请求额外先做 2~4 次 `users` 读取确认双向绑定；评论摘要每页最多拉 1000 条评论到内存。重构后只读 1 次本人文档（伴侣文档与业务查询并行），评论摘要改为帖子上的冗余字段。

真机实测方法：开发者工具「调试器 → Performance」录制冷启动；云开发控制台「云函数 → 日志」按 requestId 统计调用次数与耗时；重构前后各录 3 次取中位数填入下表。

| 浮生首屏图片可见（ms） | | |
| 日常详情可交互（ms） | | |

## 3. 手工回归清单

每项在 Android 与 iOS 各跑一遍（Skyline 渲染：开发版菜单 → 开发调试 → Switch Render → Skyline）。

**登录与资料**
- [ ] 全新微信号首次进入：显示登录页，选头像 + 昵称后进入朝夕
- [ ] 已登录冷启动：不经过登录页，直接显示缓存内容，随后静默刷新
- [ ] 清除缓存后冷启动：自动识别云端已有资料并直接进入
- [ ] 独白页退出登录 → 登录页显示已填好的资料，点「进入」恢复；杀进程重进仍停在登录页
- [ ] 编辑资料：改头像、昵称、签名后返回，独白与朝夕立即更新
- [ ] 偏好设置：切换共鸣默认筛选，回到共鸣页生效

**结伴与纪念日**
- [ ] A 复制绑定码，B 输入并发送申请；B 页面显示「等待对方回应」
- [ ] A 在结伴页看到申请，拒绝后 B 可再次申请；同意后双方都显示已结伴
- [ ] 设置纪念日后双方朝夕页计时一致，且秒数每秒跳动
- [ ] 未结伴时：朝夕、浮生、共鸣、信件都显示引导卡片，可一键去结伴页

**浮生（日常）**
- [ ] 发布纯文字 / 纯图片 / 图文（含拍照）日常，返回列表顶部立即出现
- [ ] 列表上拉加载更多、下拉刷新；新发布后翻页不重复不漏
- [ ] 按日期筛选：选择很早的日期也能查到（服务端筛选）
- [ ] 自己的帖子「更多」按钮可编辑 / 删除；对方帖子没有该按钮
- [ ] 详情页：评论、回复、编辑自己的评论、删除无回复的评论；返回列表时评论数与首评同步
- [ ] 断网时：列表显示错误态与「重试」，恢复网络后点重试成功

**共鸣（报备）**
- [ ] 发布带标签、记录时间、配图的报备；新增 / 长按删除自定义标签
- [ ] 对方看到「待处理」，标记已阅 → 评价 → 修改评价；作者端状态同步
- [ ] 三个筛选 Tab 切换与左右滑动一致；返回列表时状态已更新
- [ ] 编辑 / 删除自己的报备

**信件**
- [ ] 朝夕页信件卡显示总数与最近 3 封
- [ ] 写信（选类型、自定义类型、标题、正文、配图）→ 列表出现
- [ ] 读信、写回信预选同类型；删除自己寄出的信
- [ ] 信件列表缩略图正常显示（含对方寄来的图片）

**通用**
- [ ] 所有提交按钮在请求中显示加载并且不能重复点击
- [ ] 底部按钮、悬浮按钮不被 Home Indicator 遮挡
- [ ] 首次选头像 / 选图 / 复制绑定码时弹出微信官方隐私授权弹窗
